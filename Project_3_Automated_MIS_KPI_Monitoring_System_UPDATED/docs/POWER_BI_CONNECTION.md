# Power BI Connection

Power BI Desktop → Home → Get Data → SQL Server

Server: `localhost`
Database: `MIS_KPI_Monitoring`

Select `dbo.vw_MIS_KPI_Monthly`.

Suggested KPI cards: Total Revenue, Tickets Closed, Escalations, Average SLA %, Average Quality %.
Suggested visuals: Revenue by Month, Tickets by Department, SLA by Region, Escalation Rate by Department, Monthly KPI Trend.
